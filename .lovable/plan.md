
# خطة إضافة المحتوى الصوتي للقرآن الكريم باستخدام APIs مجانية

## الخبر السار
فيه APIs مجانية بالكامل للقرآن الصوتي - مش هتحتاج تدفع أي حاجة ولا ترفع ملفات على سيرفر. الصوت بيتحمل مباشرة من سيرفرات خارجية مجانية.

## APIs المتاحة المجانية

### 1. Al Quran Cloud API (الأفضل - الأكثر قراء)
- **الرابط:** `https://api.alquran.cloud`
- **بدون تسجيل أو مفتاح**
- **قراء كثير جدا** (مشاري العفاسي، عبد الباسط، الحصري، السديس، وغيرهم)
- **يدعم:** سورة كاملة، آية بآية
- مثال: `api.alquran.cloud/v1/surah/1/ar.alafasy` يرجع سورة الفاتحة بصوت العفاسي مع روابط MP3

### 2. QuranAPI (بسيط وسريع)
- **الرابط:** `https://quranapi.pages.dev`
- **5 قراء** (العفاسي، أبو بكر الشاطري، ناصر القطامي، ياسر الدوسري، هاني الرفاعي)
- **بدون حدود استخدام**

## الخطة التقنية

### المرحلة 1: إنشاء خدمة الصوت
إنشاء ملف `src/lib/quranAudioService.ts` يتعامل مع Al Quran Cloud API:
- دالة لجلب قائمة القراء المتاحين
- دالة لجلب روابط صوت سورة معينة بصوت قارئ معين
- دالة لجلب قائمة السور (114 سورة)

### المرحلة 2: تحديث صفحة الصوت (`SoundPage.tsx`)
- استبدال القراء الثابتين بقائمة قراء حقيقية من الـ API
- إضافة مشغل صوت يعمل فعليا (HTML5 Audio)
- إضافة قائمة اختيار السور
- عرض شريط تقدم الصوت الحقيقي
- أزرار التالي/السابق للتنقل بين السور

### المرحلة 3: تحديث صفحة القرآن (`QuranPage.tsx`)
- عرض قائمة السور الـ 114 من الـ API
- كل سورة تعرض: الاسم بالعربية، الترجمة، عدد الآيات، مكية/مدنية
- الضغط على سورة يفتح صفحة تفاصيل السورة

### المرحلة 4: إنشاء صفحة تفاصيل السورة (`SurahDetailPage.tsx`)
- عرض آيات السورة بالخط العربي
- زر تشغيل الصوت لكل آية أو السورة كاملة
- إمكانية اختيار القارئ

### المرحلة 5: إنشاء مكون مشغل الصوت (`AudioPlayer.tsx`)
- مشغل صوت ثابت في أسفل الشاشة (مثل Spotify)
- يظهر عند تشغيل أي تلاوة
- أزرار: تشغيل/إيقاف، التالي، السابق
- شريط تقدم قابل للسحب
- اسم السورة والقارئ

## التفاصيل التقنية

### الملفات الجديدة:
1. **`src/lib/quranAudioService.ts`** - خدمة التعامل مع API القرآن الصوتي
2. **`src/lib/quranData.ts`** - بيانات السور (أسماء، عدد آيات)
3. **`src/components/AudioPlayer.tsx`** - مكون مشغل الصوت العائم
4. **`src/pages/SurahDetailPage.tsx`** - صفحة تفاصيل السورة
5. **`src/hooks/useAudioPlayer.ts`** - hook لإدارة حالة الصوت

### الملفات المعدلة:
1. **`src/pages/SoundPage.tsx`** - ربط بالقراء الحقيقيين والتشغيل
2. **`src/pages/QuranPage.tsx`** - عرض قائمة السور الحقيقية
3. **`src/App.tsx`** - إضافة route جديد `/surah/:surahId`
4. **`src/components/AppLayout.tsx`** - إضافة مكون المشغل العائم

### كيف يعمل الصوت (بدون تكلفة):

```text
المستخدم يختار سورة + قارئ
        |
        v
التطبيق يطلب من API مجاني
(api.alquran.cloud)
        |
        v
API يرجع روابط MP3 مباشرة
(مستضافة على سيرفرات مجانية)
        |
        v
HTML5 Audio يشغل الرابط مباشرة
(بدون تحميل على سيرفرك)
```

### مثال على طلب API:
```text
GET https://api.alquran.cloud/v1/surah/1/ar.alafasy

الرد يحتوي على:
- بيانات السورة (اسم، عدد آيات)
- كل آية فيها رابط MP3 مباشر
- الصوت يتحمل من سيرفرات everyayah.com المجانية
```

### ترتيب التنفيذ:
1. إنشاء خدمة الصوت + بيانات السور
2. إنشاء hook مشغل الصوت
3. تحديث صفحة القرآن (قائمة السور)
4. إنشاء صفحة تفاصيل السورة
5. تحديث صفحة الصوت (القراء الحقيقيين)
6. إنشاء مكون المشغل العائم
