

# خطة إصلاح مشغل الصوت وتحسينه

## المشاكل الحالية والحلول

### 1. مدة السورة الكاملة بدلا من مدة الآية فقط
**المشكلة:** الوقت المعروض هو مدة الآية الحالية فقط، وليس السورة كاملة.
**الحل:** تتبع الوقت التراكمي لكل الآيات. عند تحميل السورة، نحسب مجموع أوقات كل الآيات المشغلة + الوقت الحالي للآية الحالية. بما أن API لا يعطي المدة مسبقا، سنتتبعها أثناء التشغيل ونعرض "الآية X من Y" مع الوقت الفعلي المتراكم.

### 2. انتقال سلس بين الآيات
**المشكلة:** فيه فجوة/تأخير عند الانتقال من آية للتالية.
**الحل:** تحميل مسبق (preload) للآية التالية أثناء تشغيل الحالية باستخدام عنصر Audio ثاني، والتبديل بينهم فورا عند انتهاء الآية.

### 3. صور القراء
**المشكلة:** يظهر أيقونة مستخدم عامة بدلا من صورة القارئ.
**الحل:** إضافة أحرف أولى ملونة (initials avatar) لكل قارئ بألوان مميزة، لأن استضافة صور حقيقية تحتاج سيرفر. كل قارئ سيكون له لون مميز ثابت.

### 4. إضافة قراء جدد
**الحل:** إضافة قراء إضافيين متوفرين في Al Quran Cloud API مثل: السديس، الشريم، سعد الغامدي، عبد الرحمن السديس، ياسر الدوسري.

## التفاصيل التقنية

### الملفات المعدلة:

**`src/lib/quranAudioService.ts`**
- إضافة حقل `color` و`initials` لكل قارئ في `POPULAR_RECITERS`
- إضافة 4-5 قراء جدد (السديس، الشريم، سعد الغامدي، ياسر الدوسري، عبد الرحمن العوسي)

**`src/hooks/useAudioPlayer.ts`**
- إضافة عنصر Audio ثاني للتحميل المسبق (preload)
- تتبع مجموع أوقات الآيات المكتملة (`elapsedPrevAyahs`)
- حساب الوقت الإجمالي = وقت الآيات المكتملة + وقت الآية الحالية
- تبديل سلس بين عنصري الـ Audio عند انتهاء الآية

**`src/pages/SoundPage.tsx`**
- استبدال أيقونة `User` بدائرة ملونة بأحرف القارئ الأولى
- عرض الوقت التراكمي للسورة
- تحديث شريط التقدم ليعكس التقدم بالنسبة لعدد الآيات

**`src/components/AudioPlayer.tsx`**
- نفس تحديثات الوقت التراكمي وأحرف القارئ

**`src/pages/SurahDetailPage.tsx`**
- تحسين انتقال الصوت بين الآيات

### بخصوص الحديث والحسان:
هذا ممكن تقنيا بنفس الطريقة لو لقينا APIs مجانية للمحتوى الصوتي. حاليا مفيش APIs صوتية مجانية للحديث بنفس جودة القرآن. ممكن نضيف نصوص أحاديث من APIs نصية مجانية كخطوة أولى.
