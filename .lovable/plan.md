

# خطة حذف الخريطة وإنشاء صفحة إعدادات الألوان

## الهدف
- حذف صفحة الخريطة والملفات المتعلقة بها نهائياً
- إنشاء صفحة إعدادات جديدة لتخصيص ألوان التطبيق
- إضافة قسم خاص بالمصريين مع ألوان واجهة مميزة لهم

---

| الملف | السبب |
|-------|-------|
| `src/pages/GlobePage.tsx` | صفحة الخريطة |

## ما سيتم إنشاؤه

### 1. صفحة الإعدادات (`src/pages/SettingsPage.tsx`)

**المميزات:**
- اختيار سمة الألوان (فاتح / داكن / تلقائي)
- اختيار اللون الرئيسي (أخضر إسلامي، ذهبي، أزرق، بنفسجي)
- تغيير حجم الخط (صغير / متوسط / كبير)
- قسم خاص للمصريين مع ألوان واجهة مميزة

### 2. نظام حفظ الإعدادات (`src/hooks/useTheme.ts`)
- حفظ الإعدادات في localStorage
- تطبيق الألوان تلقائياً عند فتح التطبيق

### 3. مكون اختيار الألوان (`src/components/ColorPicker.tsx`)
- عرض الألوان المتاحة
- معاينة اللون قبل الاختيار

## خيارات الألوان المتاحة

### السمات الأساسية
1. **فاتح (Light)** - خلفية بيضاء ونص أسود
2. **داكن (Dark)** - خلفية داكنة ونص فاتح
3. **تلقائي (Auto)** - حسب إعدادات الجهاز

### الألوان الرئيسية
1. **أخضر إسلامي** - اللون الحالي (افتراضي)
2. **ذهبي** - لون ذهبي أنيق
3. **أزرق** - لون أزرق هادئ
4. **بنفسجي** - لون بنفسجي عصري

### أحجام الخط
1. **صغير** - 14px
2. **متوسط** - 16px (افتراضي)
3. **كبير** - 18px
