

# خطة إصلاح مشغل الصوت - المشاكل المتبقية

## المشاكل المحددة

### 1. تغيير السورة لا يُحدّث المشغل فوراً
**السبب:** في `SoundPage.tsx`، عند تغيير السورة من القائمة المنسدلة (`Select`)، يتم فقط تحديث `selectedSurah` بدون إعادة تشغيل الصوت تلقائياً. المستخدم مضطر يضغط زر التشغيل يدوياً.

**الحل:** إضافة `useEffect` يراقب تغيير `selectedSurah` - إذا كان الصوت شغال، يُعيد تشغيل السورة الجديدة تلقائياً بنفس القارئ. نفس الشيء عند تغيير القارئ: بدلاً من إيقاف الصوت فقط، نُعيد التشغيل بالقارئ الجديد.

### 2. لا توجد صور للقراء
**الوضع الحالي:** يتم استخدام دوائر ملونة بأحرف عربية (initials) وهي موجودة فعلاً في الكود.

**السبب المحتمل للشكوى:** الأحرف العربية قد لا تظهر بشكل واضح على بعض الأجهزة، أو المستخدم يريد صور حقيقية.

**الحل:** سنستخدم شعار التطبيق (`src/assets/logo.png`) كصورة افتراضية لكل القراء مع الاحتفاظ بالدوائر الملونة كخلفية، مما يعطي مظهر احترافي موحد بدون تكلفة استضافة صور.

### 3. ظهور أيقونة التطبيق في إشعارات الهاتف أثناء التشغيل
**الحل:** استخدام **Media Session API** المدعومة في المتصفحات الحديثة. هذه الـ API تسمح بـ:
- عرض اسم السورة والقارئ في إشعارات الهاتف
- عرض صورة (شعار التطبيق) في الإشعار
- أزرار تحكم (تشغيل/إيقاف/التالي/السابق) في شريط الإشعارات

## التفاصيل التقنية

### الملفات المعدّلة:

**`src/pages/SoundPage.tsx`**
- إضافة `useEffect` يراقب `selectedSurah` و `selectedReciter`:
  - إذا كان الصوت يعمل وتم تغيير السورة، يُعيد التشغيل تلقائياً
  - إذا تم تغيير القارئ أثناء التشغيل، يُعيد التشغيل بالقارئ الجديد فوراً بدلاً من الإيقاف
- استخدام شعار التطبيق بجانب الدوائر الملونة للقراء

**`src/hooks/useAudioPlayer.ts`**
- إضافة تكامل مع Media Session API:
  - تعيين `navigator.mediaSession.metadata` عند بدء التشغيل (عنوان السورة، اسم القارئ، صورة الشعار)
  - تعيين `navigator.mediaSession.setActionHandler` لأزرار التحكم (play, pause, nexttrack, previoustrack)
  - تحديث الـ metadata عند تغيير السورة أو القارئ

**`src/components/AudioPlayer.tsx`**
- تحديث عرض صورة القارئ لاستخدام الشعار مع الخلفية الملونة

### مثال على Media Session API:

```text
navigator.mediaSession.metadata = new MediaMetadata({
  title: 'سورة البقرة',
  artist: 'مشاري راشد العفاسي',
  album: 'القرآن الكريم',
  artwork: [{ src: '/logo.png', sizes: '512x512', type: 'image/png' }]
});
```

هذا سيُظهر في إشعارات الهاتف:
- اسم السورة كعنوان
- اسم القارئ كفنان
- شعار التطبيق كصورة
- أزرار تحكم (تشغيل/إيقاف/التالي/السابق)

### الملفات المتأثرة:
1. `src/pages/SoundPage.tsx` - إصلاح التبديل التلقائي + صور القراء
2. `src/hooks/useAudioPlayer.ts` - إضافة Media Session API
3. `src/components/AudioPlayer.tsx` - تحسين عرض القارئ
4. نسخ `src/assets/logo.png` إلى `public/logo.png` لاستخدامها في الإشعارات
