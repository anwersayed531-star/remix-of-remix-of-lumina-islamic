# خطة إضافة الحديث الشريف من مصادر معتمدة مع الترجمات

## المصدر
استخدام `fawazahmed0/hadith-api` — API مجاني بدون مفتاح، مستضاف على jsDelivr CDN، يغطي الكتب الستة (البخاري، مسلم، أبو داود، الترمذي، النسائي، ابن ماجه) بالإضافة لموطأ مالك، الأربعين النووية، والأحاديث القدسية.

**النص العربي** يأتي دائماً من `ara-{book}`، والترجمة تأتي من لغة المستخدم إن وُجدت، وإلا تُعرض الترجمة الإنجليزية كاحتياطي.

## لغات الترجمة المتوفرة في API
`eng` (إنجليزي), `fra` (فرنسي), `ben` (بنغالي), `ind` (إندونيسي), `rus` (روسي), `tam` (تamil), `tur` (تركي), `urd` (أردو) — باقي لغات التطبيق (56 لغة) تستخدم الإنجليزية كاحتياطي.

## الملفات المطلوب إنشاؤها/تعديلها

### 1. `src/lib/hadithService.ts` (جديد)
- تعريف الكتب المتاحة (10 كتب) مع معرفاتها وأسمائها العربية والإنجليزية
- دالة `fetchBookInfo()` لجلب الأقسام/الفصول من `info.json` (مع تخزين مؤقت)
- دالة `fetchSectionHadiths(book, sectionNo, langCode)` لجلب الأحاديث من النسخة العربية + المترجمة لقسم معين
- خريطة تحويل رموز لغات التطبيق إلى رموز لغات API
- واجهات TypeScript للبيانات

### 2. `src/pages/HadithPage.tsx` (تعديل كامل)
- عرض قائمة الكتب في الأعلى (شبكة أو قائمة منسدلة)
- عند اختيار كتاب: عرض قائمة الفصول/الأقسام (مع عدد الأحاديث في كل قسم)
- عند اختيار قسم: عرض الأحاديث
  - لكل حديث: رقم الحديث، النص العربي (خط أميري)، الترجمة (إن لم تكن العربية)
  - تحميل تدريجي مع مؤشر تحميل
- بحث في الأحاديث (اختياري - مرحلة لاحقة)

### 3. `src/lib/translations/*.ts` (تعديل كل ملفات الترجمة الـ 56)

### 4. ملفات الترجمة - تحديث قسم `hadith` في كل اللغات الـ 56
- تحديث `ar.ts` و `en.ts` أولاً كقالبين
- ثم إضافة المفاتيح الجديدة لباقي اللغات (الـ 54 الأخرى)
- اللغات تُدمج تلقائياً مع العربية كاحتياطي عبر `deepMerge`

## السلوك
- اللغة العربية: عرض النص العربي فقط
- اللغات الأخرى: عرض النص العربي + الترجمة باللغة المختارة (أو الإنجليزية كاحتياطي)
- لا تخزين على السحابة — البيانات تُجلب من CDN خارجي عند الطلب
